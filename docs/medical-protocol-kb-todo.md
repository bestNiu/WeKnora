## 已知事实（避免重复踩坑）

- **eDoc 同一集成账号不能并发同步**：多数据源同时触发会互踢 token，表现为大批 `edoc_fetch_failed`。必须串行；cron 已错峰。
- **docreader 在预览并发 ≥4 时会崩**（`RestartCount` 曾 16→65）：预览预生成必须单并发 + 健康门控。
- **`read_document` 的 query 是同一 chunk 内 AND 语义**，多词组合易全空；扫描件要走 OCR chunk（已修）。
- **连接器去重键是 `datasource_id + external_id`**，不同数据源的相同内容会各入一份；跨目录去重只能用 `file_hash` 事后做。
